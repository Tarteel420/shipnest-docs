## Return a shipped order

<Steps>
<Step>

### Click Return

In **Shipped** or **To Process**, click **Return** on the order's row. A **Returned Shipments** page opens.

</Step>
<Step>

### Check the addresses

The addresses are swapped for you: **Ship to** is your address and **Ship from** is the customer.

<Screenshot src="/images/shipments/return-shipment-form.png" alt="Returned Shipments page" caption="A return created from a shipped order." />

</Step>
<Step>

### Check the package and rate

Confirm the package details and choose a rate, as you would for a normal [shipment](/docs/shipments/shipping-an-order).

</Step>
<Step>

### Create the return

Click **Create return and ship**. The return label is created and kept linked to the original shipment.

</Step>
</Steps>

Returned orders appear in the **Returned** tab.

## Stand-alone return

To create a return that isn't linked to an existing order, click **▾** next to **New shipment** and choose **Return shipment**, then fill in the customer's address, items and package.

<Callout>
  Return labels use the **Return format** (PDF or ZPL) set on the carrier account. See [Managing carriers](/docs/configuration/carriers/managing-carriers#label-formats).
</Callout>
