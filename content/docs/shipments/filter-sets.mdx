---
title: Filter sets
description: Save filter combinations and switch between them in one click.
---

A **filter set** is a saved combination of [filters](/docs/shipments/search-and-filters). Your default filter set is applied when you open the Shipments page.

## Create a filter set

<Steps>
<Step>

### Apply the filters

Open **Filters** and choose the filters you want.

</Step>
<Step>

### Save them

Click **Save as filter set** at the bottom of the panel (or **+ New filter set** under **Filter sets**) and name the set when prompted.

</Step>
</Steps>

## Switch filter sets

Click the filter-set menu next to **Filters** (it shows the current set, for example **My Default**) and choose another set.

## Manage filter sets

In the Filters panel, click **Manage filter sets**.

<Screenshot src="/images/shipments/ship-manage-filter-sets.png" alt="Manage filter sets dialog" caption="Rename, set the default or delete filter sets." />

- **Rename** — edit the name in the box.
- **Make default** — click the ☆ star. The default set shows a **DEFAULT** chip.
- **Delete** — click **×**.

Click **Done** to finish.

<Callout>
  If you change filters after loading a set, use **Revert to filter set** (the circular arrow at the top of the panel) to go back to the saved version.
</Callout>
