Click the order date / number area of any row on the [Shipments page](/docs/shipments) to open **Order details**. This is where you check and edit an order before shipping it.

<Screenshot src="/images/shipments/order-details-top.png" alt="Order details page" caption="The top of the Order details page." />

## Header buttons

| Button | What it does |
| --- | --- |
| **Update and ship** | Saves your changes and ships the order with the selected rate. See [Ship an order](/docs/shipments/shipping-an-order). |
| **Ship with Shopify** | Shopify orders only — buys the label and fulfils the order through Shopify in one step. |
| **Slip** ▾ | Print or download the packing slip. |
| **+ Shipment** | Add another shipment to the order. See [Multiple shipments](/docs/shipments/multiple-shipments). |
| **Clone** ▾ | Copy the order. See [Cloning orders](/docs/shipments/cloning-orders). |
| **Cancel** | Cancel the order. See [Cancelling orders](/docs/shipments/cancelling-orders). |

The order number at the top links to the order in its marketplace (the ↗ icon).

## Tabs

- **Shipping details** — the order, addresses, packages and rates (described below).
- **Order shipping log** — a history of everything that happened to the order. See [Shipping log](/docs/shipments/shipping-log).

## Order summary

Each shipment has its own tab (for example **Primary shipment**). The summary card shows:

- The store, **Alt #** (alternate order number — click the copy icon to copy), **Delivery Date** and status chip (for example *Ready to ship*).
- Chips such as **Returning customer** and the risk level (for example **No Risk**).
- **Risk, holds & tags** — click **Show** to see the **Risk level** and **Recommendation**.
- **Order date**, **Ship by date**, **Value**, **Tax** and **Shipping paid by customer**.
- Each item with its **SKU**, **Price**, **Quantity** and **Subtotal**.

## Shipping address

<Screenshot src="/images/shipments/order-details-address-packages.png" alt="Shipping address and Packages sections" caption="Shipping address (left) and Packages (right)." />

| Field | Notes |
| --- | --- |
| **Ship from** | Choose one of your [carrier accounts' ship-from addresses](/docs/configuration/carriers/managing-carriers#manage-ship-from-addresses). Click the pencil to edit. |
| **Ship to** | The customer's name, company, address, country, city, state, ZIP, email and phone. Required fields are marked \*. |
| **Skip validation** | Ship without validating the address. See [Address validation](/docs/account-settings/address-validation). |
| **Residential address** | Tick if delivering to a home. |
| **Payment Terms** | **Sender** (you pay) or **Recipient**. |

## Packages, items and rates

- **Packages** — dimensions, weight, package type and more. See [Packages and items](/docs/shipments/packages-and-items).
- **Rates** — the services you can choose from. See [Rates and services](/docs/shipments/rates-and-services).
