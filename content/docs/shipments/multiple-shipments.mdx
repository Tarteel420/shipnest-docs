---
title: Multiple shipments and partial shipping
description: Split one order into several shipments.
---

An order starts with one **Primary shipment**. You can add more shipments — for example when items ship from different places, on different days, or with different services.

## Add a shipment

<Steps>
<Step>

### Open the order

Open the order's [Order details](/docs/shipments/order-details) page.

</Step>
<Step>

### Click + Shipment

Click **+ Shipment** in the header. A new shipment tab appears next to **Primary shipment**.

</Step>
<Step>

### Set it up

On the new tab, set the address, packages, items and rate, just like the primary shipment.

</Step>
</Steps>

## How multi-shipment orders appear

- In the order list, the order shows a **n shipments** chip (for example *2 shipments*).
- While some shipments are shipped and others aren't, the order is in **Partially Shipped**. It moves to **Shipped** once every shipment is shipped.
- Use the **Multi-shipment orders** and **Multi-package orders** filters to find them. See [Search and filters](/docs/shipments/search-and-filters).

<Callout>
  **Multiple packages vs multiple shipments:** packages in the same shipment travel together with one service. Separate shipments can use different services, addresses and ship dates. See [Packages and items](/docs/shipments/packages-and-items).
</Callout>
