---
title: Cloning orders
description: Make a copy of an order to ship again.
---

Cloning creates a new order based on an existing one — useful for sending a replacement or a missing part.

| Option | What is copied |
| --- | --- |
| **Clone** | The original order's address and shipment details. |
| **Clone with items** (Clone ▾) | The address details, letting you create a separate package with different items. |

You can clone from the order row (**Clone** / **Clone ▾**) or from the [Order details](/docs/shipments/order-details) header.

<Callout>
  **Clone** is disabled on [Needs Attention](/docs/shipments/needs-attention) orders until the problem is fixed.
</Callout>
