---
title: Keyboard shortcuts
description: Set shortcuts for frequent shipment actions.
---

Go to **Account settings → Keyboard shortcuts**. Shortcuts apply to **your account only** — other users set their own.

<Screenshot src="/images/account-settings/acct-keyboard-shortcuts.png" alt="Keyboard shortcuts settings" />

| Shortcut | Default | What it does |
| --- | --- | --- |
| **Bulk fetch rates** | Ctrl + X | Fetches carrier rates for the selected orders, the same as applying the account's [Fetch Rates](/docs/automation/fetch-rates) rule. |
| **Ship all with Shopify** | Ctrl + S | Buys labels and fulfils the selected (or ready-to-ship) Shopify orders in one step. |

## Change a shortcut

Click the shortcut keys (or the pencil — *Click to change*) and press the new key combination.

<Callout type="warn" title="Browser conflicts">
  Ctrl + X and Ctrl + S are also your browser's **Cut** and **Save** shortcuts. ShipNest saves them and takes priority while you are on the Shipments page. To avoid the clash, click **Use Ctrl + Shift + X instead** / **Use Ctrl + Shift + S instead**.
</Callout>
