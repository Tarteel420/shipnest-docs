---
title: Address validation
description: Settings that control how shipping addresses are checked before a label is created.
---

Go to **Account settings → Address validation**.

<Screenshot src="/images/account-settings/acct-address-validation.png" alt="Address validation settings" />

| Setting | What it does | Default |
| --- | --- | --- |
| **Skip address validation by default** | New shipments start with **Skip validation** ticked. You can still validate an individual order. Applies to new shipments going forward. | Off |
| **Auto-apply suggested corrections** | Automatically accepts the suggested address correction instead of asking you to confirm each time. | Off |

On an individual order, tick or untick **Skip validation** above the Ship to address. See [Order details](/docs/shipments/order-details#shipping-address).

Orders with an invalid address go to [Needs Attention](/docs/shipments/needs-attention).
