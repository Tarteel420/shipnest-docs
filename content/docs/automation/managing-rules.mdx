---
title: Managing rules
description: Enable, edit, duplicate, reorder and archive automation rules.
---

Saved rules are listed under **Rules (n)** on the Automation Rules page, grouped by category (for example *ORDER VALIDATION*, *FETCH RATES*, *OTHER RULES*).

<Screenshot src="/images/automation/ar-rule-saved.png" alt="Rules list" />

Each row shows the run position, name, status (**paused** / **testing**), number of conditions and the rule type, followed by the action icons.

| To… | Do this |
| --- | --- |
| Turn a rule on or off | Use the toggle on its row. |
| Edit a rule | Click the **pencil** to reopen its panel, change it, and click **Save Rule** / **Update rule**. |
| Copy a rule | Click the **Duplicate rule** icon. |
| Stop a rule but keep its history | Click the **Archive** icon. *Archiving a rule stops it without deleting history.* |
| Change the run order | Drag the row by its handle (⠿). |
| Turn several rules on/off | Tick their checkboxes, then click **Enable selected (n)** or **Disable selected**. |

## Change the run order

Rules run top-to-bottom on new matching orders. Drag a row by its handle to move it up or down. Rules can only be reordered **within their own category**.

## Go live after testing

A rule created in **Test mode** shows **testing**. To make it live, click the pencil, switch **Test mode** off, and save.
