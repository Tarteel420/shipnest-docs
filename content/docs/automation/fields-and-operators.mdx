## Operators

| Field type | Operators |
| --- | --- |
| **Numbers and dates** (Order Total, Order Date…) | `=`, `!=`, `<`, `>`, `<=`, `>=`, is null, is not null, between, not between. Dates use MM/DD/YYYY. |
| **Text** (Item Title, SKU…) | `=`, `!=`, contains, begins with, ends with, does not contain, is null, is not null, in, not in |
| **Tags** | has any of, has all of, has none of |
| **Yes / No** (PO Box, Repeat Customer…) | No operator — click **Yes** or **No**. |

## AND, OR and groups

- **AND** — every condition must match.
- **OR** — any one condition can match.
- **Add Group** — creates a nested set of conditions with its own AND/OR, for example *Market = Shopify AND (Order Total > 500 OR Total Item Quantity > 10)*.
- **Add item group** (Make your package) — all conditions in the group must match **the same item**.
