---
title: Connect WooCommerce
description: Connect a WooCommerce store with REST API keys.
---

## What you need

A WooCommerce REST API **Consumer key** and **Consumer secret** (created in your WordPress admin under WooCommerce's REST API settings) and your **Store URL**.

<Steps>
<Step>

### Open the WooCommerce form

Go to **Configurations → Webstore settings**, click **+ New webstore**, then click **WooCommerce** (the *woo* logo).

<Screenshot src="/images/configuration/webstore-woocommerce.png" alt="WooCommerce configuration form" />

</Step>
<Step>

### Enter the details

| Field | Enter |
| --- | --- |
| **Web store name** \* | A name to recognise this store. |
| **Consumer key** \* | Your WooCommerce consumer key. |
| **Consumer secret** \* | Your WooCommerce consumer secret. |
| **Store URL** \* | Your store's web address. |

</Step>
<Step>

### Authenticate

Click **Authenticate**, then [switch on the carrier accounts](/docs/configuration/webstores/managing-webstores#choose-carrier-accounts-for-a-webstore) for the store.

</Step>
</Steps>
