---
title: Custom packages
description: Save the box sizes you use most so you can pick them in one click.
---

Custom packages are reusable box definitions. You can pick them on an order's **Package type**, as a carrier's **Default Package Type**, and in automation rules such as [Make your package](/docs/automation/make-your-package).

Go to **Configurations → Custom packages**.

<Screenshot src="/images/configuration/custom-packages-list.png" alt="Custom Packages list" />

## Create a package

<Steps>
<Step>

### Click Create New Package

The **Create New Package** panel opens.

<Screenshot src="/images/configuration/custom-package-create.png" alt="Create New Package panel" />

</Step>
<Step>

### Fill in the details

| Field | Notes |
| --- | --- |
| **Package name** \* | Up to 100 characters. |
| **Description** | Optional. |
| **Size** \* | Length × Height × Width, in inches. |
| **Max Weight** \* | In lbs. |

</Step>
<Step>

### Create

Click **Create**. The button is available once the required fields are filled in.

</Step>
</Steps>

## Manage packages

- **Search** — find a package by name.
- **Active** — switch a package on or off.
- **⋮ → Edit** — change a package.
