The **Configurations** menu in the sidebar holds everything ShipNest needs before you can ship.

| Page | Purpose |
| --- | --- |
| [Webstore settings](/docs/configuration/webstores) | Connect the marketplaces your orders come from. |
| [Carrier settings](/docs/configuration/carriers) | Connect UPS, FedEx and USPS accounts for rates, labels and tracking. |
| [Printing template](/docs/configuration/printing-template) | Choose cloud or desktop printing and your label sizes. |
| [Custom packages](/docs/configuration/custom-packages) | Save the box sizes you use most. |
| [Automation rules](/docs/automation) | Let ShipNest act on orders automatically. |
| [Tags](/docs/configuration/tags) | Create tags to organise orders. |

<Callout>
  New to ShipNest? Follow the [Setup checklist](/docs/getting-started/setup-checklist) to configure these in the right order.
</Callout>
