## Set the default account

On **Configurations → Carrier settings**, select the **Default** radio button on the account you want as default.

## Label formats

Each account has two switches:

- **Label format** — PDF or ZPL for outgoing shipping labels.
- **Return format** — PDF or ZPL for [return labels](/docs/shipments/returns).

Use **ZPL** for thermal label printers and **PDF** for standard printers. Label sizes are set in the [Printing template](/docs/configuration/printing-template).

## Edit an account

Click **⋮ → Edit** on the account's row. The account page has two tabs:

- **Account information** — Account number, Client id, Client secret and Default Package Type. Click **Save changes**.
- **Shipping addresses** — the account's ship-from addresses.

## Manage ship-from addresses

<Steps>
<Step>

### Open Shipping addresses

Click **⋮ → Edit** on the account, then open the **Shipping addresses** tab.

<Screenshot src="/images/configuration/carrier-shipping-addresses.png" alt="Carrier shipping addresses" />

</Step>
<Step>

### Add an address

Click **Add new address**, fill in Company, First name, Address 1, City, State, Zip code, Email and Phone number (required), and click **Add Address**.

</Step>
<Step>

### Edit or delete

Use **⋮ → Edit** or **Delete** on an address row.

</Step>
</Steps>

The address you choose under **Ship from** on an order comes from these lists. See [Order details](/docs/shipments/order-details#shipping-address).

## Delete an account

Click **⋮ → Delete** on the account's row.
