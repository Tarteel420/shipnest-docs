---
title: Overview tab
description: Headline numbers for the selected period.
---

<Screenshot src="/images/reports/reports-overview.png" alt="Reports Overview tab" />

| Widget | Shows |
| --- | --- |
| **Total orders** | Number of orders in the period. |
| **Total order value** | Sum of order values. |
| **Average order value** | Total order value ÷ total orders. |
| **Gift box value** | Value of gift boxes, reported separately from product revenue. |
| **Revenue trend** | Order value per month. |
| **Top 5 products by product revenue** | Your best-selling products in the period. |
| **Carrier on-time rate** | Share of packages delivered on time per carrier. Only shown when packages have both a promised date and a delivery time. |
| **Order value by marketplace** | Each marketplace's share of order value. |
