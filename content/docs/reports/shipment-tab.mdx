---
title: Shipment tab
description: Shipping cost and carrier performance.
---

| Report | Shows |
| --- | --- |
| **Cost per shipment** | Shipping cost by carrier. |
| **Carrier performance** | On-time rate and spend by carrier. |
| **Void vs. shipped ratio** | Cancellation (void) rate against fulfilled shipments. |

Use the chart-type selector on each report to switch the chart.

<Callout type="warn">
  If a report shows *This report could not be loaded*, try another date range or reload the page. If it continues, contact [Support](/docs/support).
</Callout>
