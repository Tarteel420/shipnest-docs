---
title: User roles
description: What each ShipNest role can see and do.
---

ShipNest uses role-based access. What you see in the sidebar depends on your role.

| Role | Access |
| --- | --- |
| **Admin** | Full access to all ShipNest modules, features and actions. |
| **User** | Currently the same access as Admin. |
| **Warehouse** | Only the **Scan Labels** page. All other menus are hidden. |

Whatever the role, users only ever see their own organization's data. See [Your data and privacy](/docs/getting-started/data-and-privacy).

Pages that need a specific permission show a message such as **You don't have permission to manage users** or **You don't have access to this page — Your role doesn't grant permission to view this page. Contact your organization admin if you believe this is a mistake.**

<Callout type="warn" title="Ask your admin">
  Users and roles are managed under **Admin → User Management** by people with permission. If you need access to a page, contact your organization admin.
</Callout>
