---
title: Key concepts
description: The terms you will see throughout ShipNest.
---

| Term | Meaning |
| --- | --- |
| **Webstore** | A connected marketplace account, such as a Shopify store or Amazon seller account. Orders sync from webstores. See [Webstores](/docs/configuration/webstores). |
| **Marketplace** | The sales channel an order came from. Orders you create yourself in ShipNest show the marketplace **ShipNest**. |
| **Carrier account** | Your UPS, FedEx or USPS account, connected so ShipNest can fetch rates and buy labels. See [Carriers](/docs/configuration/carriers). |
| **Ship-from address** | The pickup address saved on a carrier account. Each shipment uses one. |
| **Shipment** | One set of packages sent together with one carrier service. An order has a **Primary shipment** and can have more. See [Multiple shipments](/docs/shipments/multiple-shipments). |
| **Package** | One box or envelope in a shipment, with its own dimensions, weight and label. |
| **Package type** | A carrier box (for example a FedEx flat-rate box), **Box/Other**, or one of your [custom packages](/docs/configuration/custom-packages). |
| **Rate / service** | The price and delivery speed a carrier offers, such as *FedEx 2Day®*. See [Rates and services](/docs/shipments/rates-and-services). |
| **Label** | The shipping label you print and stick on the package — PDF or ZPL. |
| **Packing slip (Slip)** | The document listing the items in the order, used for picking and packing. |
| **Tag** | A coloured label you attach to orders to group them. See [Tags](/docs/configuration/tags). |
| **Automation rule** | An *If this, then that* rule that runs on new orders automatically. See [Automation](/docs/automation). |
| **Filter set** | A saved combination of Shipments filters. See [Filter sets](/docs/shipments/filter-sets). |
| **PrintWise** | ShipNest's optional cloud-printing service, which sends labels straight to a printer. See [Printing](/docs/printing). |
| **Returning customer** | A green ★ star next to the customer name. It marks a repeat customer — it is not a priority flag. |
