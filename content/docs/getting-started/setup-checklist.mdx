---
title: Setup checklist
description: Configure these items, in this order, before you ship your first order.
---

ShipNest needs to know **where your orders come from** (webstores), **who will carry them** (carrier accounts) and **how labels should print**. Work through this checklist once; after that, day-to-day work happens on the [Shipments](/docs/shipments) page.

<Steps>
<Step>

### Connect your carrier accounts

Add at least one UPS, FedEx or USPS account. ShipNest uses it to fetch live rates, buy labels and track packages.

→ [Carriers](/docs/configuration/carriers)

</Step>
<Step>

### Connect your webstores

Connect each marketplace you sell on (Shopify, Amazon, eBay, Walmart, Newegg, Newegg Business, Best Buy, WooCommerce, Temu). Orders start syncing into ShipNest automatically.

→ [Webstores](/docs/configuration/webstores)

</Step>
<Step>

### Choose which carriers each webstore can use

Open each webstore and switch on the carrier accounts it should use.

→ [Managing webstores](/docs/configuration/webstores/managing-webstores#choose-carrier-accounts-for-a-webstore)

</Step>
<Step>

### Set up label printing

Decide between desktop printing and PrintWise cloud printing, and pick your ZPL and PDF label sizes.

→ [Printing template](/docs/configuration/printing-template) and [Printing overview](/docs/printing)

</Step>
<Step>

### Save your common box sizes (optional)

Save the boxes you ship in most often so they can be picked in one click.

→ [Custom packages](/docs/configuration/custom-packages)

</Step>
<Step>

### Create tags and automation rules (optional)

Tags help you group orders. Automation rules can validate orders, set packages, choose carriers and fetch rates for you.

→ [Tags](/docs/configuration/tags) and [Automation](/docs/automation)

</Step>
<Step>

### Review account settings

Decide which problems send an order to **Needs Attention**, whether to skip the **To Process** step, and how addresses are validated.

→ [Account settings](/docs/account-settings)

</Step>
</Steps>

<Callout type="info">
  Once this is done, go to [Ship an order](/docs/shipments/shipping-an-order) to create your first label.
</Callout>
