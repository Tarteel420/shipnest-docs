ShipNest is a shipping and order-fulfilment platform for businesses that sell on more than one online marketplace. It brings your orders from every connected store into one place, lets you compare live carrier rates, create and print shipping labels, track shipments, and handle returns and cancellations — without logging in to each marketplace separately.

If you are new, read the pages in this section in order — each one builds on the last.

## What ShipNest connects to

| Type | Supported |
| --- | --- |
| **Marketplaces (webstores)** | Shopify, Amazon, eBay, Walmart, Newegg, Newegg Business, Best Buy, WooCommerce, Temu |
| **Carriers** | UPS, FedEx, USPS |
| **Label formats** | PDF and ZPL (thermal) |
| **Printing** | Your browser / desktop printing, or PrintWise cloud printing |
