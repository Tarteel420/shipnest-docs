---
title: Glossary
description: Shipping and ShipNest terms explained.
---

| Term | Meaning |
| --- | --- |
| **Alt #** | The alternate (marketplace) order number shown on Order details. |
| **BTO** | BTO kits and BTO Sync. The BTO Sync column shows sync status (it needs a BTO configuration on your account); BTO kit fields are available in automation rules. |
| **Courier service** | The carrier service used, for example *UPS Ground*. |
| **Declared value** | The value declared to the carrier for a package. |
| **DSR** | Delivery signature requirement — set with the [DSR rule](/docs/automation/dsr-rule). |
| **Expedited** | Faster delivery that the customer paid extra for. |
| **Flat rate package** | A carrier-provided box with a fixed price, for example a FedEx One Rate box. |
| **Label batch** | A saved PDF of labels or packing slips from Slip Preview, Ship all, Ship all with Shopify or a reprint. Kept for 7 days in [Label downloads](/docs/shipments/label-downloads). |
| **Downtime notice** | A banner announcing a planned ShipNest update. See [Downtime notices](/docs/getting-started/downtime-notices). |
| **Label Created** | Tracking status: the label exists but the carrier hasn't scanned the package yet. |
| **Payment terms** | Who pays for shipping — **Sender** or **Recipient**. |
| **PDF / ZPL** | Label formats. PDF prints on standard printers; ZPL is for thermal label printers. |
| **PrintWise** | ShipNest's cloud printing service. |
| **Residential address** | A home delivery address; carriers may price these differently. |
| **Ship-by date** | The date the order should leave your warehouse. A red *late* badge shows how many days it is overdue. |
| **Signature confirmation** | Default Confirmation, No Signature, Direct Signature or Adult Signature. |
| **Stock type** | The label or page size your printer uses, for example 4 × 6. |
| **Test mode** | Runs an automation rule without generating labels; only simulation logs are written. |
| **To Process** | Shipped orders whose labels haven't been scanned or picked up yet. |
| **Void** | Cancelling a shipping label with the carrier. |
